1. Typography

The system pairs Plus Jakarta Sans for clean, high-legibility UI text with Playfair Display for editorial destination punchlines.

Variable Font Family Weights Usage
var(--font-heading) Plus Jakarta Sans 600, 700, 800 Section titles, hero headlines, card titles
var(--font-body) Plus Jakarta Sans 400, 500, 600, 700 Body paragraphs, buttons, form controls
var(--font-serif) Playfair Display 600, 700 (Italic) Editorial quotes, destination punchlines

6. Responsive Breakpoints

Device Tier Media Query Behavior
Desktop > 1024px Full 4-5 column grids, sticky AI planner 2-column sidebar
Tablet @media (max-width: 1024px) Nav links fold into mobile drawer; card grids switch to 2 columns
Mobile @media (max-width: 768px) Search inputs stack to 1 column; single column vertical card feeds

7. Team Developer Rules

  • ✅ Always use CSS custom properties (e.g. var(--expedia-blue)) instead of hardcoding raw hex codes.
  • ✅ Ensure dark mode readiness by relying on surface variables (--white, --cream, --ink-900).
  • ✅ Maintain 1 primary CTA per visual hierarchy to avoid confusing user focus.
